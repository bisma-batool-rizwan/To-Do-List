# 🚀 TaskFlow - Smart Task Management App

TaskFlow is a modern and responsive task management web application designed to help users organize their daily activities, manage priorities, and improve productivity.

With a clean dashboard interface, users can create, track, filter, and manage tasks efficiently with a smooth and user-friendly experience.
## 🌐 Live Demo

Check out the live version of TaskFlow here:

🔗 https://taskflow-todo-list-app.netlify.app/
## ✨ Features

- ✅ Create and manage tasks
- 📝 Add task title and description
- 🏷️ Categorize tasks
- ⭐ Set task priority (High, Medium, Low)
- 📅 Add due dates
- ✔️ Mark tasks as completed
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- 🔍 Search tasks instantly
- 🎯 Filter tasks by category, priority, and status
- 📊 Productivity statistics dashboard
- 🌙 Dark mode support
- 🔔 Notification panel
- 👤 Profile dropdown
- 💾 Local storage support (tasks remain saved after refresh)
- 📱 Responsive design for different screen sizes


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
- Google Fonts
